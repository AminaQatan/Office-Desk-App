Office Desk TV (شاشة المكتب للتلفاز) - Android TV / Google TV app
=================================================================
A small Android app that opens https://aminaqatan.github.io/Office-Desk-App/ full screen on the TV.
The web app sees "OfficeDeskTV" in the browser name and turns on TV mode (remote arrows, OK, Back).

Built by GitHub Actions (.github/workflows/tv-app.yml) from this zip; the result is tv.apk on the site.
office-desk-tv.p12 is the signing key of this TV app only: keep it, so new builds install over the old one.

Developer: Ms. Amina Qatan
