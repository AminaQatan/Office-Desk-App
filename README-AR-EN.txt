# شاشة المكتب — تطبيق Android وiPhone

تطبيق ويب تقدمي (PWA) يُثبَّت من المتصفح: الوقت ومواقيت الصلاة، المهام وجدول الأسبوع، الملاحظات والتسجيلات والملفات، التركيز، والأذكار.

## الملفات (في المجلد الرئيسي للمستودع، ومعها مجلد media للمشاهد)
- index.html — التطبيق كاملاً
- manifest.webmanifest — بيانات التثبيت
- service-worker.js — العمل بدون إنترنت
- adhan-aqsa.mp3 — أذان المسجد الأقصى (ناجي قزاز)
- media/ — أصوات «الجو» الطبيعية (16 ملفاً)، وصور مشاهدك الخاصة عند إضافتها. التطبيق لا يعتمد على أي خادم خارجي.
- icon-192.png وicon-512.png وicon-maskable-512.png وapple-touch-icon.png — الأيقونات

## النشر
1. ارفع كل الملفات أعلاه إلى المجلد الرئيسي في مستودع GitHub (Add file ← Upload files)، واستبدل القديمة.
2. من Settings → Pages فعّل النشر من الفرع main والمجلد /(root).
3. افتح رابط GitHub Pages. إذا ظهرت النسخة القديمة، أغلق التطبيق وافتحه مرة ثانية ليتحدّث.

## التثبيت
- Android: افتح الرابط في Chrome ثم «تثبيت التطبيق».
- iPhone/iPad: افتح الرابط في Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».


## الجديد في هذه النسخة
- حذف الموسيقى من «الجو» مع بقاء أصوات الطبيعة، وصوت نقر لطيف (فقاعة، قطرات، جرس، أو بدون).
- أذان المسجد الأقصى مدمج، مع اختيار أذان خاص للفجر وتنبيه قبل الأذان.
- صفحة «ملاحظاتي»: ملاحظات لاصقة ملوّنة، قوائم تحقق، تسجيلات صوتية، صور وملفات (PDF وWord ونصوص) مع «اقرأ لي» والمشاركة.
- مهام بالإيموجي مع اليوم والوقت، وجدول الأسبوع بالتاريخين الميلادي والهجري، واحتفال عند الإنجاز.
- خلفيات مرسومة للمناسبات الإسلامية والعُمانية والخليجية والتعليمية والعائلية والفصول، حسب دولة المدينة المختارة، مع عدّاد المناسبة القادمة وبطاقة تهنئة للمشاركة.
- الشكل الافتراضي هو شكل التطبيق الأصلي نفسه (كحلي وخط ريدكس)، ومن الإعدادات تقدر تختار ثيم «لؤلؤي» الأوف وايت أو «كيوت وردي»، وخطاً آخر (المراعي، بلكس، تجوال، كوفي)، وتُظهر «حاشي».
- في «الجو»: مشاهد مرسومة بالكود، و50 خلفية للمناسبات والفصول، وأصوات طبيعة جديدة محفوظة داخل التطبيق.
- وضع رمضان (الإفطار والإمساك)، وتذكيرات الماء والحركة وسورة الكهف، ونسخة احتياطية.

## ملاحظات
- البيانات محفوظة في جهازك فقط. احفظ نسخة احتياطية من الإعدادات لنقلها إلى جهاز آخر.
- يحتاج الإنترنت لأول مرة فقط للخطوط، ولعرض مستندات Word وقراءة ملفات PDF بصوت، ولمشاهد «الجو» وأصواتها.
- الإملاء الصوتي والقراءة الصوتية يعتمدان على دعم المتصفح في جهازك.
